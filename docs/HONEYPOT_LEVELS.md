# Уровни взаимодействия ловушек (Honeypot Interaction Levels)

В платформе HoneyForge реализована поддержка всех трех уровней взаимодействия: **Low**, **Medium** и **High**, каждый из которых решает свои задачи в эшелонированной обороне.

---

## Сравнительная таблица уровней

| Характеристика | Low-Interaction | Medium-Interaction | High-Interaction |
| :--- | :--- | :--- | :--- |
| **Что эмулирует** | Открытые сокеты, правдоподобные TCP-баннеры (FTP, Telnet, Redis). Нет реальной логики сервиса. | Виртуальные демоны: Fake-SSH (Paramiko), Fake Web Admin, In-memory виртуальный шелл, виртуальная ФС. | Реальная изолированная операционная система в контейнере/песочнице с авто-сбросом снапшотов. |
| **Собираемые данные** | Факт сканирования портов, IP-источник, TCP SYN/ACK, баннер-запросы. | Учетные записи (логины/пароли), команды шелла, скачиваемые вредоносные файлы (SHA-256), SQLi. | Полный TTY ввод/вывод, скомпилированные эксплойты, lateral movement в изолированном сегменте. |
| **Уровень риска** | **Нулевой** (нет исполнения пользовательского кода). | **Минимальный** (код исполняется в in-memory виртуальном симуляторе). | **Контролируемый** (требуются лимиты ресурсов, cgroups, изоляция сети). |
| **Ресурсоемкость** | Микроскопическая (сотни ловушек на одном узле). | Низкая (десятки ловушек на узел). | Средняя/высокая (выделенные sandbox-контейнеры). |
| **Основная цель** | Периметральное раннее оповещение, обнаружение слепых сканеров Shodan/Masscan/Nmap. | Сбор актуальных словарей брутфорса, TTPs атакующих, перехват дропперов и майнеров. | Исследование APT-группировок, 0-day эксплойтов и сложных цепочек атак. |

---

## 1. Low-Interaction Реализация в HoneyForge
- **Модуль:** `honeyforge_agent.traps.low_interaction.LowInteractionMultiPortTrap`
- **Протоколы:** FTP (порт 2121), Telnet (порт 2323), Redis (порт 6379), HTTP (порт 8080).
- **Механизм:** Асинхронный сокет-сервер слушает входящие соединения, немедленно отправляет реалистичный баннер актуальной версии (`220 ProFTPD 1.3.5 Server`, `Ubuntu 22.04 LTS login:`, `-ERR operation not permitted`), считывает первые probe-байты атакующего и генерирует событие `port_scan` или `banner_probe`.

## 2. Medium-Interaction Реализация в HoneyForge
- **Модули:** `honeyforge_agent.traps.fake_ssh.FakeSSHTrap` и `honeyforge_agent.traps.fake_web.FakeWebTrap`
- **Fake SSH Daemon:**
  - Полное соблюдение протокола SSH на базе библиотеки Paramiko.
  - Аутентичный баннер `SSH-2.0-OpenSSH_8.9p1 Ubuntu-3ubuntu0.6`.
  - Захват вводимых пар логин/пароль с логированием в `auth_attempt`.
  - При вводе правильных decoy-учеток (или тестовых `root:admin123`) открывается интерактивный virtual shell.
  - Поддержка набора команд: `whoami`, `id`, `uname -a`, `pwd`, `ls`, `cat /etc/passwd`, `wget`, `curl`, `ps`, `exit`.
  - Перехват загрузок файлов: симуляция скачивания, подсчет SHA-256 хэша артефакта (`file_download` Critical Event).
  - Asciinema-style запись сессии: хронологический лог ввода/вывода для последующего воспроизведения оператором SOC.
- **Fake Web Admin:**
  - Эмуляция веб-портала авторизации Enterprise SSO.
  - Логирование попыток подбора паролей, SQL-инъекций (`' OR '1'='1`) и обхода директорий (`../../etc/passwd`).

## 3. High-Interaction Песочница (Bonus)
- Профиль `Isolated-Sandbox-High` генерирует артефакт контейнера с жесткими ограничениями:
  - `cap_drop: ALL`
  - Отсутствие доступа в интернет и прод-сеть (изолированный bridge)
  - Подключение агента к TTY для логирования необработанного потока команд.
